# Armstrong公理推导推理规则
## 1. 合并规则$X\rightarrow Z,X\rightarrow Y\Rightarrow X\rightarrow YZ$
$X\rightarrow Z,X\subset U\Rightarrow XX=X\rightarrow XZ$
$X\rightarrow Y,Z\subset U\Rightarrow XZ\rightarrow YZ$
$X\rightarrow XZ,XZ\rightarrow YZ\Rightarrow X\rightarrow YZ$

## 2.伪传递规则$X\rightarrow Y,WY\rightarrow Z\Rightarrow XW\rightarrow Z$
$X\rightarrow Y,W\subset U\Rightarrow XW\rightarrow WY$
$XW\rightarrow WY,WY\rightarrow Z\Rightarrow XW\rightarrow WY$

## 3.分解规则$X\rightarrow Y, Z\subset Y\Rightarrow X\rightarrow Z$
$Z\subset Y\Rightarrow Y\rightarrow Z$
$X\rightarrow Y,Y\rightarrow Z\Rightarrow X\rightarrow Z$

# 求最小函数依赖集

给定：
$$
\large
F = \begin{cases} 
AB \rightarrow C & D \rightarrow EG \\ 
C \rightarrow A & BE \rightarrow C \\ 
BC \rightarrow D & CG \rightarrow BD \\ 
ACD \rightarrow B & CE \rightarrow AG 
\end{cases}
$$


1. 右部最小化，$F$变为
$$\large
F = \{AB \rightarrow C,\; D \rightarrow E,\; D \rightarrow G,\; C \rightarrow A,\; BE \rightarrow C,\; BC \rightarrow D,\; CG \rightarrow B,\; CG \rightarrow D,\; ACD \rightarrow B,\; CE \rightarrow A,\; CE \rightarrow G\}
$$

2. 去掉冗余的函数依赖

对每个 $X \rightarrow Y$，从 F 中删去后求 $X^+$，若 $Y \in X^+$ 则该依赖冗余。

| 考察    | 删去后求闭包                         | 结果     |
| ----- | ------------------------------ | ------ |
| AB→C  | $(AB)^+ = \{A,B\}$，不含 C        | 保留     |
| D→E   | $(D)^+ = \{D,G\}$，不含 E         | 保留     |
| D→G   | $(D)^+ = \{D,E\}$，不含 G         | 保留     |
| C→A   | $(C)^+ = \{C\}$，不含 A           | 保留     |
| BE→C  | $(BE)^+ = \{B,E\}$，不含 C        | 保留     |
| BC→D  | $(BC)^+ = \{A,B,C\}$，不含 D      | 保留     |
| CG→B  | $(CG)^+ = \{A,B,C,D,E,G\}$，含 B | **删除** |
| CG→D  | $(CG)^+ = \{A,C,G\}$，不含 D      | 保留     |
| ACD→B | $(ACD)^+ = \{A,C,D,E,G\}$，不含 B | 保留     |
| CE→A  | $(CE)^+ = \{A,B,C,D,E,G\}$，含 A | **删除** |
| CE→G  | $(CE)^+ = \{A,C,E\}$，不含 G      | 保留     |
最后得到$F$
$$\large
F = \{AB \rightarrow C,\; D \rightarrow E,\; D \rightarrow G,\; C \rightarrow A,\; BE \rightarrow C,\; BC \rightarrow D,\; CG \rightarrow D,\; ACD \rightarrow B,\; CE \rightarrow G\}
$$
3. 左部最小化

对每个左部非单属性的依赖 $X_1X_2\ldots X_n \rightarrow Y$，依次挡住一个属性，在 **原 F₂** 下求剩余属性的闭包，若含 Y 则该属性冗余。

①AB → C
- 挡 A 求 $(B)^+_{F_2} = \{B\}$ → 不含 C
- 挡 B 求 $(A)^+_{F_2} = \{A\}$ → 不含 C 

→ 保留

②BE → C
- 挡 B 求 $(E)^+ = \{E\}$ → 不含 C 
- 挡 E 求 $(B)^+ = \{B\}$ → 不含 C 

→ 保留

③ BC → D
- 挡 B 求 $(C)^+ = \{A,C\}$ → 不含 D
- 挡 C 求 $(B)^+ = \{B\}$ → 不含 D

→ 保留

④ CG → D
- 挡 C 求 $(G)^+ = \{G\}$ → 不含 D
- 挡 G 求 $(C)^+ = \{A,C\}$ → 不含 D

→ 保留

⑤ ACD → B
- 挡 A 求 $(CD)^+=\{A,B,C,D,E,G\}$→ 含 B

→ ACD → B 化简为 CD → B

⑥ CE → G
- 挡 C 求 $(E)^+ = \{E\}$ → 不含 G
- 挡 E 求 $(C)^+ = \{A,C\}$ → 不含 G

→ 保留

最终结果

$$\large
F_{\min} = \begin{cases}
AB \rightarrow C & D \rightarrow E \\
D \rightarrow G & C \rightarrow A \\
BE \rightarrow C & BC \rightarrow D \\
CG \rightarrow D & CD \rightarrow B \\
CE \rightarrow G &
\end{cases}
$$
