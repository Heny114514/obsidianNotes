# 6-7.授权与撤销
关系模式如下：
职工(职工号，姓名，年龄，职务，工资，部门号)
部门(部门号，名称，经理名，地址，电话号)
授权-撤销语句：

1. 王明对两个表有SELECT权限
```sql
授权
GRANT SELECT
ON TABLE 职工, 部门
TO 王明;

撤销
REVOKE SELECT
ON TABLE 职工, 部门
FROM 王明;
```

2. 李勇对两个表有INSERT和DELETE权限
```sql
授权
GRANT INSERT, DELETE
ON TABLE 职工, 部门
TO 李勇;

撤销
REVOKE INSERT, DELETE
ON TABLE 职工, 部门
FROM 李勇;
```

3. 每个职工只对自己的记录有SELECT权限
```sql
CREATE VIEW V_own_staff AS
SELECT * FROM 职工 WHERE 职工号=USER;
授权
GRANT SELECT ON V_own_staff TO PUBLIC;

撤销
REVOKE SELECT ON V_own_staff FROM PUBLIC;
```

4. 用户刘星对职工表有 SELECT 权限，对“工资”字段具有更新权限
```sql
授权
GRANT SELECT, UPDATE(工资) ON TABLE 职工 TO 刘星;

撤销
REVOKE SELECT, UPDATE(工资) ON TABLE 职工 FROM 刘星;
```

5. 用户张新具有修改这两个表的结构的权限
```sql
授权
GRANT ALTER ON TABLE 职工, 部门 TO 张新;

撤销
REVOKE ALTER ON TABLE 职工, 部门 FROM 张新;
```

6. 用户周平具有对两个表的所有权限，并具有给其他用户授权的权限
```sql
授权
GRANT ALL PRIVILEGES ON 职工, 部门 TO 周平 WITH GRANT OPTION;

撤销
REVOKE ALL PRIVILEGES ON 职工, 部门 FROM 周平;
```

7. 用户杨兰具有从每个部门职工中 SELECT 最高工资、最低工资、平均工资的权限，但不能查看每个人的工资
```sql
CREATE VIEW V_dept_salary AS
SELECT 部门号, MAX(工资) AS 最高工资, MIN(工资) AS 最低工资, AVG(工资) AS 平均工资
FROM 职工
GROUP BY 部门号;
授权
GRANT SELECT ON V_dept_salary TO 杨兰;

撤销

REVOKE SELECT ON V_dept_salary FROM 杨兰;
```

# 6.完整性约束
```sql
创建部门表
CREATE TABLE 部门 (
    部门号 INT PRIMARY KEY,
    名称 VARCHAR(100) NOT NULL,
    经理姓名 VARCHAR(100),
    电话 VARCHAR(20)
);

创建职工表
CREATE TABLE 职工 (
    职工号 INT PRIMARY KEY,
    姓名 VARCHAR(100) NOT NULL,
    出生日期 DATE NOT NULL,
    职务 VARCHAR(100),
    工资 DECIMAL(10, 2) CHECK (工资 > 0),
    部门号 INT,
    FOREIGN KEY (部门号) REFERENCES 部门(部门号),
    CHECK (TIMESTAMPDIFF(YEAR, 出生日期, CURDATE()) <= 65)
);
```
