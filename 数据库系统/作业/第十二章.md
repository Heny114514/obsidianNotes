# 9. 什么样的并发调度是正确的调度？
正确的并发调度是可串行化的调度。即多个事务并发执行的结果，与它们按某种顺序串行执行的结果完全相同。可串行化是数据库并发控制中正确性的基本标准。

# 10. 设  $T_{1}$、 $T_{2}$、 $T_{3}$ 是如下的三个事务 (A 的初值为 0)。
 $T_{1}$:  $A := A + 2$;
 $T_{2}$:  $A := A * 2$;
 $T_{3}$:  $A := A ** 2$; (即  $A \leftarrow A^{2}$)

① 若这三个事务允许并发执行，则有多少种可能的正确结果？请一一列举出来。
1.   
    T₁ → T₂ → T³：  
    T₁: 0+2=2  
    T₂: 2\*2=4  
    T₃: 4²=16
    
2. T₁ → T₃ → T₂：  
    T₁: 2  
    T₃: 2²=4  
    T₂: 4\*2=8
    
3. T₂ → T₁ → T₃：  
    T₂: 0\*2=0  
    T₁: 0+2=2  
    T₃: 2²=4
    
4. T₂ → T₃ → T₁：  
    T₂: 0  
    T₃: 0²=0  
    T₁: 0+2=2
    
5. T₃ → T₁ → T₂：  
    T₃: 0²=0  
    T₁: 0+2=2  
    T₂: 2\*2=4
    
6. T₃ → T₂ → T₁：  
    T₃: 0  
    T₂: 0\*2=0  
    T₁: 0+2=2

综上一共有四种结果：2，4，8，16
② 请给出一个可串行化的调度，并给出执行结果。
```text
T1: Read(A) A=0
T1: A := A+2 → 2
T1: Write(A)
T2: Read(A) A=2
T2: A := A*2 → 4
T2: Write(A)
T3: Read(A) A=4
T3: A := A**2 → 16
T3: Write(A)
```
执行结果：A = 16。
③ 请给出一个非串行化的调度，并给出执行结果。
```text
T1: Read(A) → 0  
T2: Read(A) → 0  
T1: A := 0+2 → 2, Write(A)  
T2: A := 0*2 → 0, Write(A)  
T3: Read(A) → 0  
T3: A := 0**2 → 0, Write(A)
```
结果 A = 0。这不等于任何串行结果，所以是非串行化的。
④ 若这三个事务都遵守两段锁协议，请给出一个不产生死锁的可串行化调度。
```text
T1: Lock-X(A)  
T1: Read(A), A:=A+2, Write(A)  
T1: Unlock(A)  
T2: Lock-X(A)  
T2: Read(A), A:=A*2, Write(A)  
T2: Unlock(A)  
T3: Lock-X(A)  
T3: Read(A), A:=A**2, Write(A)  
T3: Unlock(A)
```
这是串行执行，满足两段锁且无死锁。结果 A=16。
⑤ 若这三个事务都遵守两段锁协议，请给出一个产生死锁的调度。
```text
T1: Lock-X(A)  
T2: Lock-X(A)  // 等待 T1 释放  
T1: (执行中，但未释放锁)  
T3: Lock-X(A)  // 等待 T1 或 T2
```
